# Implementation Plan: Footer.vue Component

## 1. Overview

Overwrite the existing stub at `src/components/landing/Footer.vue` with a clean, professional footer that closes the landing page seamlessly. The footer is the last element on the page and uses the darkest background shade (`--color-bg-deepest`). No scroll-reveal animations are needed.

## 2. Component Structure

Three conceptual rows inside a Bootstrap `.container`:

1. **Accompanying Phrase Row** — centered, italic, slightly larger; the emotional page close.
2. **Links & Contact Row** — horizontal inline nav links + clickable email; centered.
3. **Copyright & Legal Row** — small muted text; copyright + beta disclaimer at the very bottom.

## 6. Methods

```ts
function scrollToSection(sectionId: string): void {
  const element = document.getElementById(sectionId)
  if (!element) {
    return
  }
  const offset = 70
  const targetPosition = element.getBoundingClientRect().top + window.scrollY - offset
  window.scrollTo({ top: targetPosition, behavior: 'smooth' })
}
```

## 8. Edge Cases

- **Responsive stacking**: `.footer-nav` uses `flex-wrap` so links wrap naturally on narrow screens. Bootstrap grid ensures center alignment.
- **Navbar offset**: `scrollToSection` subtracts 70px so anchor links from the footer land correctly below the fixed navbar.
- **Missing section IDs**: If an anchor target is absent, `getElementById` returns null and the click is silently ignored.
- **Email link**: Uses `mailto:` protocol; opens the user's default mail client with the pre-filled address.
- **Text wrapping**: `line-height: 1.6` on the phrase prevents cramped multi-line display on mobile.
- **No scroll-reveal**: The footer does not import `useScrollReveal` and contains no `data-reveal` attributes.
