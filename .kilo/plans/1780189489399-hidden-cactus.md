## Implementation Notes

### Component Architecture
- **File**: `src/components/landing/FaqSection.vue`
- **Background**: `--color-bg-slate` (per style guide §3.1, #8)
- **Section ID**: `faq` (matches Navbar `Dudas` link and navbar scroll target)
- **Content Source**: `landing-content.es.md` §8 — 9 question/answer pairs
- **Component**: Bootstrap 5 Accordion with dark theme overrides
- **Scroll Reveal**: `data-reveal` on section title + accordion container

### TypeScript Interface
```ts
interface FaqItem {
  question: string
  answer: string
}
```

### Bootstrap 5 Accordion Pattern
```html
<div class="accordion" id="faqAccordion">
  <div v-for="(item, index) in faqItems" :key="index" class="accordion-item">
    <h2 class="accordion-header">
      <button
        class="accordion-button"
        :class="{ collapsed: index !== 0 }"
        type="button"
        data-bs-toggle="collapse"
        :data-bs-target="'#faqCollapse' + index"
        :aria-expanded="index === 0 ? 'true' : 'false'"
        :aria-controls="'faqCollapse' + index"
      >
        {{ item.question }}
      </button>
    </h2>
    <div
      :id="'faqCollapse' + index"
      class="accordion-collapse collapse"
      :class="{ show: index === 0 }"
      data-bs-parent="#faqAccordion"
    >
      <div class="accordion-body">
        {{ item.answer }}
      </div>
    </div>
  </div>
</div>
```
